Auto Sync Source List

                                
Automatically sync articles from Intercom into the Pull registry every 24 hours at approximately 00:00 UTC.

                            

                        

                        

                            
                            Disabled

 How it works

                        
    
                            
  •  When enabled, a scheduled job runs every day at ~00:00 UTC.
    • 
                            
  •  It calls the same "Sync Source List" function from the Pull section.
    • 
                            
  •  New articles from Intercom are added to the Pull registry automatically.
    • 
                            
  •  Existing articles are updated if their metadata changed.
    • 
                            
  •  You can still manually sync at any time from the Pull section.
    • 
                        

                    

                


                
                

                    

                        

                            

                            

                                
Auto Pull Articles

                                
Automatically pull full content for all articles with "Needs Update" or "Never Pulled" status every day at 01:30 UTC.

                            

                        

                        

                            
                            Disabled
                        

                    


                    

                        

                            

                                 Status
                                
                                    Disabled
                                
                            

                            

                                 Last Run
                                Never
                            

                            

                                 Last Result
                                —
                            

                            

                                 Next Run
                                —
                            

                        


                        

                            
                            
                        

                    


                    
                    

                        
 How it works

                        
    
                            
  •  When enabled, a scheduled job runs every day at ~01:30 UTC (after the source list sync).
    • 
                            
  •  It finds all articles in the Pull registry with "Never Pulled" or "Needs Update" status.
    • 
                            
  •  It pulls the full content (title + body) from Intercom for each article.
    • 
                            
  •  Articles already up-to-date are skipped.
    • 
                            
  •  You can still manually pull articles from the Pull section at any time.
